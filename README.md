# NHIS Health Insurance Administration System
## STYAM INTEGRATED SERVICES LIMITED

This is the initial functional application foundation for the NHIS administration, billing, invoices, members, providers, claims, plans, reports, users and settings system.

### Run locally
1. Install Node.js 20+.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

### Demo accounts
- Admin: admin@nhis.local / Admin@123
- Finance: finance@nhis.local / Finance@123

### Important
This build is a functional development foundation, not a certified production deployment. Before production use, replace demo credentials, configure a real database/backup strategy, HTTPS, secrets management, email/SMS/payment integrations, security hardening, audit retention and formal UAT.
